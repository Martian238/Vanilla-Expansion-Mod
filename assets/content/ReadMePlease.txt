关于参考此模组Json写法的说明
Instruction about referring to this mod

此模组的所有内容均可作为参考，完全开源
Copying and referring to any code of this mod are all allowed

可以参考叠Drawer、叠Part、叠子弹和特效、PartProgress的扩展写法等内容
There are drawers, parts, bullets and effects, also the more complex form of PartProgress that can be learnt and copied

对于纯Json模组开发者，注意模组中有一些Java内容是不能作为参考的
For those who make Json mods, please notice that there are some Java content that cannot be copied into Json mods

除多配方厂外涉及到Java的Json内容文件已在其中用注释标注所含的Java内容情况
Except for the multicrafters, all content with Java had their Java usage displayed in their comments (//...)

多配方厂的Json含有'recipe'接口，它们的type也跟原版工厂明显不同，可以根据这个分辨
The key 'recipe' exists in multicrafters' Json files. Their type name is also obviously different from other factories

当然，这些Java内容中也有常规的、来自原版type的接口，Json可以参考，例如'drawer'
Of course these Java content written in Json have keys that come from vanilla types, which Json can use, like 'drawer'

模组的Json并不是绝对完美的，有的地方缩进比较乱，有的地方会出现未知接口或拼写错误，参考的时候加以注意即可
Json files of this mod are not perfect. There might be some issues like spelling errors

详细情况也可到对应qq群问群友，群号可以在模组简介以及发布在Bilibili的下载渠道视频上找到
Also you can come to our Discord server (Vanilla Expansion) to discuss these things
If there's no response, try to put your questions in '中文' channel. Just use English. Those Chinese admins may help you
